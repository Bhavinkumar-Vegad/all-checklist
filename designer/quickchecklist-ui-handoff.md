## Before Handoff:

* [ ] Final screens cover empty, loading, error, and success states.
* [ ] Spacing, type, and color use the design system tokens.
* [ ] Interactive states exist: default, hover, focus, disabled, active.
* [ ] Breakpoints are specified for mobile, tablet, and desktop.
* [ ] Assets are exported at the right size and format (SVG when possible).

## Spec:

* [ ] Redlines or auto-layout make spacing unambiguous.
* [ ] Fonts, weights, and line heights are listed.
* [ ] Copy is final or marked as placeholder with an owner.
* [ ] Links to prototypes, user flows, and tickets are in the file.

## Accessibility:

* [ ] Contrast is checked for text and essential icons.
* [ ] Focus order and keyboard behavior are noted for custom widgets.
* [ ] Touch targets are large enough on mobile.
* [ ] Motion is optional or has a reduced-motion variant if it is intense.

## Developer Ready:

* [ ] Components are named the way engineering will look for them.
* [ ] Icons and illustrations are in a shared library, not scattered frames.
* [ ] Dev mode or inspect is enabled for the latest version.
* [ ] A walkthrough is scheduled for anything that is not obvious.
* [ ] Open questions are listed instead of hidden in comments.
