## Problem Fit:

* [ ] The design solves the stated user job, not only a visual request.
* [ ] Primary action is obvious on each key screen.
* [ ] Content hierarchy matches what users need first.

## Consistency:

* [ ] Color, type, radius, and elevation match the system.
* [ ] Similar actions look and behave the same across screens.
* [ ] Icons and labels do not conflict with platform conventions.

## Completeness:

* [ ] Empty, error, permission-denied, and offline states are designed.
* [ ] Long text, large numbers, and translations have room to grow.
* [ ] Forms show validation in place.

## Usability:

* [ ] Navigation is predictable and a user can undo destructive actions.
* [ ] Contrast and tap size meet a basic accessibility bar.
* [ ] The flow is as short as it can be without hiding needed choices.

## Feedback:

* [ ] Notes are specific (screen, element, suggested change).
* [ ] Separate must-fix from nice-to-have.
* [ ] Agree who will update the file and by when.
