## Keyboard and Focus:

* [ ] Tab through every page and confirm focus is visible.
* [ ] Confirm you can operate menus, dialogs, and custom widgets without a mouse.
* [ ] Check focus is trapped in modal dialogs and returned when they close.
* [ ] Verify skip-to-content or equivalent exists on long pages.

## Structure and Text:

* [ ] Confirm a single h1 and a logical heading order.
* [ ] Check page titles are unique and describe the page.
* [ ] Verify language is set on the html element.
* [ ] Confirm link text makes sense out of context (avoid "click here" only).

## Forms:

* [ ] Every input has a visible label that stays when the field is filled.
* [ ] Required fields are indicated in text, not only by color.
* [ ] Errors are announced and tied to the field that failed.
* [ ] Placeholder text is not used as the only label.

## Media and Color:

* [ ] Images that convey meaning have alt text; decorative images are empty or CSS.
* [ ] Video has captions if the content is required to understand the page.
* [ ] Text and controls meet contrast requirements for body and UI text.
* [ ] Information is not communicated by color alone.

## Assistive Tech and Motion:

* [ ] Test a primary flow with a screen reader (NVDA, VoiceOver, or TalkBack).
* [ ] Confirm ARIA is used only when native HTML cannot do the job.
* [ ] Check reduced-motion preferences are respected for non-essential animation.
* [ ] Zoom the page to 200% and confirm content still works without horizontal scrolling where possible.

## Sign-Off:

* [ ] Log issues with WCAG success criteria when you know them.
* [ ] Retest after fixes with keyboard and one screen reader.
* [ ] Record which pages and devices were covered.
