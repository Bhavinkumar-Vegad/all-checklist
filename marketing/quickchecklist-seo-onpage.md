## Basics:

* [ ] Each page has a unique title tag that matches search intent.
* [ ] Each page has a unique meta description that invites a click.
* [ ] There is one clear h1 that matches the primary topic.
* [ ] URL is short, readable, and uses hyphens.

## Content:

* [ ] Primary keyword appears naturally in the title, h1, and first paragraph.
* [ ] Headings describe real sections, not keyword stuffing.
* [ ] Internal links point to related pages with descriptive anchor text.
* [ ] Images have descriptive file names and alt text.
* [ ] Thin or duplicate content is rewritten or canonicalized.

## Technical:

* [ ] Page is indexable (no accidental noindex on live).
* [ ] Canonical URL is correct.
* [ ] Page is mobile friendly and usable.
* [ ] Important content is in HTML, not only in images.
* [ ] Structured data is valid if you use it (article, product, FAQ, org).

## Track:

* [ ] Page is in the sitemap.
* [ ] Search Console shows no blocking errors for the URL.
* [ ] Analytics records the page view and primary conversion.
