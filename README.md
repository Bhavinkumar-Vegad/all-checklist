## Categories

Each checklist is a markdown file named `quickchecklist-{name}.md`. Live pages on [QuickChecklist](https://quickchecklist.dailytool.app/) load these files from this repository.

### Developer (`developer/`)
- New website, web app, and mobile app kickoff
- Existing / freelance website, web app, and mobile app kickoff
- React setup (Vite) and Angular setup
- Next.js setup, Git workflow, pull request, code review
- API development and pre-deployment

### Tester (`tester/`)
- General website, full website, web / mobile / desktop app testing
- API testing and performance testing (web, mobile, desktop)
- Security, accessibility, smoke, regression, test plan, and UAT

### Manager (`manager/`)
- Sprint planning, project kickoff, release planning
- Risk management and stakeholder meetings
- Requirement gathering lives at the repo root as `quickchecklist-requirements-gathering-checklist.md` (already used by the live Manager page)

### Marketing (`marketing/`)
- On-page SEO, landing page, content publish
- Social campaign, email campaign, and product launch

### DevOps (`devops/`)
- CI/CD pipeline, Docker deployment
- Production readiness and incident response

### Designer (`designer/`)
- UI handoff and design review

Root `checklist-en.md` is the original general website UI/functionality checklist.
